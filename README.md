UART Command Console

Designed a UART communication system operating at 115,200 baud, allowing a PC to send commands to an FPGA to control LEDs, read switches, and receive responses.

4-Bit ALU

Developed a 4-bit Arithmetic Logic Unit (ALU) in Verilog, implementing arithmetic and bitwise operations such as addition, subtraction, AND, OR, and XOR.

Tools

- Verilog HDL

- AMD Vivado

- Digilent Basys 3 FPGA
